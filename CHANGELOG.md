# Changelog

## 3.4.0

- Refreshed Windows workspace colors, pointer lighting and opening transition.

- Shared Windows/Linux workspace, first-launch onboarding and direct workspace shortcuts.
- Bounded local recent activity with reusable inputs, output-folder actions and privacy controls.
- Intent-aware English/Arabic action search, debounce, keyboard navigation and stable scrolling.
- Bounded asynchronous thumbnail worker with cache invalidation and safe widget lifecycle.
- Live batch counts, stable result details, meaningful failure/cancellation headings and next actions.
- Refined dark/light tables and cards, platform fonts and Linux action/output scrolling.


- Added Linux runtime support alongside Windows.
- Added a Linux control window, optional tray, X11 shortcuts and Wayland shortcut guidance.
- Added per-user Linux installer, application launcher, autostart and optional Nautilus/Dolphin actions.
- Isolated platform paths, process termination, output opening and desktop integration in platform_runtime.py.
- Added Linux font/theme fallbacks and portable media/Office subprocess handling.
- Added cross-platform CI and native GUI workflow checks.


## 3.3.0

This release consolidates the work developed in this session under the requested public version 3.3.0.

- Grouped action menu, favorites and usage ranking.
- Quality presets and expandable advanced controls.
- Structured per-file results, errors, output paths and retry.
- Saved conversion/output presets with update and deletion.

- Visual PDF organizer: reorder, rotate, delete, add PDFs, undo and preview.

- Module boundaries and architecture/design documentation.
