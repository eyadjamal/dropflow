# DropFlow 3.2.0 — UI Screenshot Set

Captured from the DropFlow 3.2.0 source UI at 2× DPI for documentation and presentation use.

## Screens

### 01 — Home / Drop Zone
`01-home-drop-zone.png`

Fresh launch. Shows the draggable floating drop zone, hover glow, supported file types, and the global shortcut hint.

### 02 — Action Menu
`02-action-menu.png`

Three PDFs dropped. Shows the file summary, PDF thumbnails, search field, full action list, and favorite-star state.

### 03 — Search and Favorites
`03-search-favorites.png`

The search field filtered to “compress.” Shows only matching actions and the filled favorite star on “Compress PDFs.”

### 04 — Settings
`04-settings.png`

Full Settings screen: global shortcut, autostart, detected helper programs, OCR languages, interface language, remember-position, update checker, Explorer menu, Appearance, reset, log, cancel, and save.

### 05 — Appearance
`05-appearance.png`

Theme picker with live preview, twelve theme cards including Acrylic Glass, Windows Glass, and Windows 11 Glass, accent swatches, custom accent picker, contrast readout, Reduce Motion, Apply, and Cancel.

### 06 — Video Compression
`06-video-options.png`

Video compression options: CRF quality slider, resolution, target size, NVIDIA GPU option, and Back/Run actions.

### 07 — Batch Progress
`07-batch-progress.png`

Batch progress with Step 2 / 5, determinate progress bar, recent activity, elapsed time, and Cancel.

### 08 — Completed Result
`08-result-card.png`

Successful compression result with before/after sizes, saved percentage, Open folder, and Close.

### 09 — Arabic / RTL
`09-arabic-rtl.png`

Arabic action menu with mirrored header, RTL action text, mirrored file strip, search field, and favorite stars.

## Use

- Place these PNGs in the repository under `screenshots/` or a release post.
- Link them with Markdown:

```markdown
![DropFlow home](screenshots/01-home-drop-zone.png)
```

- For GitHub releases, use the raw GitHub URL after uploading:

```text
https://raw.githubusercontent.com/eyadjamal/dropflow/main/screenshots/01-home-drop-zone.png
```

## Notes

- Images use the Midnight theme.
- The action-menu and Arabic screenshots are tall because the full action list is visible.
- Screenshot backgrounds are neutral dark for presentation use.
- The close button is omitted from the home screenshot so the rounded window corner stays clean; the other screens show it.
